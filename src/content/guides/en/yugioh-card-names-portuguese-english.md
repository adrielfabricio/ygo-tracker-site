Collectors who buy Yu-Gi-Oh! cards in Brazil, or trade with players there, deal with two names for the same card. Cards printed in Portuguese have translated names, while decklists, databases and many shops use the English name. Knowing both saves you from searches that return nothing and, worse, from buying the wrong card.

## Why the names change

The Yu-Gi-Oh! TCG is printed in several languages, and each one translates the card name. The card itself is the same: same effect, same identification number, same tournament rules. Only the printed text changes.

The set code under the artwork shows the printing language: **EN** for English and **PT** for Portuguese. A code like MACR-EN036 means card 036 from the Maximum Crisis set, printed in English.

Note the last two: some names are not translated and stay the same in both languages.

## Where each name shows up

- **Tournament decklists and deck sites:** almost always in English.
- **Brazilian shops:** it varies. Some list cards by the Portuguese name, others by the English one, and many accept both in search.
- **Card databases:** the main name is usually English, with translations as an extra field.

## Tips to avoid buying the wrong card

1. **Keep both names** for every card you are hunting.
2. **Check the artwork and the set code** before you buy, especially when a translated name looks like another card's.
3. **When in doubt, search by the English name**, which is the most widely used.
